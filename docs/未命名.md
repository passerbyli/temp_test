## 原始需求（头脑风暴）
> 现在有一个存量vue项目在做代码规约整改。提供了2个规约集的excel，比如必须双引号，逗号结尾，2个空格缩进，不允许有console，重复率不能超过6%，函数入参不能超过5个，带默认参数必须放在最后等等， 总共150多条。  
现在根据这些规则已经构建了prettier.config.js，eslint.config.js但还有大量问题需要人为处理，想让ai帮忙解决，搭建一套可复用的ai项目，并能自动扫描问题再解决问题再扫描，直到问题全部解决完。  
已经根据规则集制作了一个扫描的skill，里面有一个eslint项目，通过指定代码目录扫描问题，并通过python生成问题报告的excel，包括规约类型，涉及代码文件路径，行号等信息。能正常使用。  
现在的想法是让ai通过这个skill扫描的村里代码，根据生成的excel自动修改并更新状态。改完后再扫描再解决，直到所有问题清零。  
但是之前发现如果excel的问题非常多，ai改了几个就说改完了，改每个问题都非常慢。  
针对这个任务要怎么通过ai高效完成，之前制作的检查代码问题的skill有什么优化点，是否思路正确。测试怎么做，需要引入subagents/hooks这些吗

给出的建议是
1. 任务分片+自动闭环+批量处理
2. 构建pipeline（不能依赖模型记忆，需要引入外部任务系统）
3. excel不适合作为AI主要输入
4. 规则必须分层，level1:prettier、eslint；level2:AST自动修复；level3:AI辅助
