# 项目总览

> Karpathy llm-wiki 架构：`raw/` → `wiki/` → `scheme/`

## 三目录

| 目录 | 作用 | 内容 |
|------|------|------|
| `raw/` | 原始数据 | Excel、代码仓信息 |
| `wiki/` | 知识文章 | LLM 生成的 Markdown |
| `scheme/` | 结构索引 | JSON 元数据 |

## 快速入口

| 入口 | 说明 |
|------|------|
| [wiki/_index.md](../wiki/_index.md) | 知识文章总览 |
| [scheme/](../scheme/) | 结构化索引（JSON） |
| [wiki/US/_index.md](../wiki/US/_index.md) | 用户故事索引 |
| [wiki/API/_index.md](../wiki/API/_index.md) | 接口文档索引 |

## 数据流

```
raw/Excel → raw-to-wiki.sh → wiki/Markdown
wiki/Markdown → gen-scheme.sh → scheme/JSON
wiki/Markdown → gen-knowledge.sh → wiki/功能地图/
wiki/ + raw/ → build-context.sh → AI 上下文
```

## 命令

| 命令 | 用途 |
|------|------|
| `/import` | 导入 Excel → wiki |
| `/gen-knowledge` | 生成功能地图 |
| `/build-context` | 构建 AI 上下文 |
| `/test-coverage` | 测试覆盖检查 |
